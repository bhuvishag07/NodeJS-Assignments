# NodeJS-Basics-Assignment

## Assignment Description

This assignment introduces the basics of Node.js and demonstrates how to create and execute simple Node.js programs.

The assignment contains two programs:

1. **app.js** – Displays basic messages in the terminal.
2. **introduction.js** – Displays a personal introduction using `console.log()`.

## Project Structure

```text
NodeJS-Basics-Assignment
│
├── app.js
├── introduction.js
└── README.md
```

## Prerequisites

* Node.js installed on the system
* Visual Studio Code or any code editor
* Terminal / Command Prompt

## Task 1: First Node.js Program

### File Name

`app.js`

### Description

The `app.js` program displays two messages in the terminal using `console.log()`.

### Code

```javascript
console.log("Hello, Node.js!");
console.log("I am learning backend development");
```

### Command Used

```bash
node app.js
```

### Expected Output

```text
Hello, Node.js!
I am learning backend development
```

## Steps to Run the Programs

### Step 1: Open the Project

Open the `NodeJS-Basics-Assignment` folder in Visual Studio Code.

### Step 2: Open the Terminal

Open the VS Code terminal using:

```text
Terminal → New Terminal
```

### Step 3: Run app.js

Execute:

```bash
node app.js
```

The terminal will display:

```text
Hello, Node.js!
I am learning backend development
```

### Step 4: Run introduction.js

Execute:

```bash
node introduction.js
```

The terminal will display the personal introduction.
